# Kakeizu (家系図作成アプリ)

JavaScriptで家系図を作成・共有するためのWebアプリケーションです。本READMEでは、開発開始前に洗い出した主要機能と要件をまとめています。

## 想定ユーザー
- 自分や親族の家系図を整理したい個人ユーザー
- 家族史を共有したい家族・親族グループ
- 家系調査を行う系譜学者・研究者

## 基本機能
### 1. 人物管理
- 氏名（姓・名・ミドルネーム）・ふりがなの入力
- 生年月日、没年月日、年齢の自動計算
- 性別・続柄・職業・メモなど任意属性の追加
- 画像アップロード（顔写真、家紋など）
- タグ付けによる分類

### 2. 家系図編集
- ドラッグ＆ドロップによる人物カードの配置
- 親子・夫婦・兄弟などの関係線の作成と編集
- 世代ごとの自動レイアウト切り替え（縦型／横型／ツリー）
- ズーム・パン操作
- 履歴と元に戻す／やり直す機能

### 3. データ管理
- プロジェクト単位で複数の家系図を保存
- JSON/CSV/画像（PNG/SVG）でのエクスポート
- GEDCOMファイルのインポート／エクスポート対応
- バージョン履歴と差分閲覧

### 4. 検索・ナビゲーション
- 名前・タグ・年号などでの検索
- 特定人物を中心としたフォーカス表示
- 系列ごとのハイライト表示

### 5. コラボレーション
- 招待制の共同編集（閲覧／編集権限の付与）
- コメント・注釈機能
- 変更履歴と通知

### 6. アカウント・セキュリティ
- メールアドレスまたは外部プロバイダーによる認証
- 二段階認証のサポート
- バックアップと暗号化されたデータ保存

## 技術スタック候補
- フロントエンド: React / Vue / Svelte などのモダンフレームワーク
- 状態管理: Redux / Pinia / Zustand など
- 描画ライブラリ: D3.js / Cytoscape.js / vis.js / SVG + Canvas API
- バックエンド: Node.js（Express / NestJS など）
- データベース: PostgreSQL / MongoDB / Neo4j（系譜データ向け）
- 認証: Auth0 / Firebase Authentication / 自前実装（JWT）
- デプロイ: Vercel / Netlify / AWS / GCP

## ユースケースフロー例
1. ユーザー登録・ログイン
2. 新規家系図プロジェクトの作成
3. 人物カードの追加・関係設定
4. レイアウト調整と注釈追加
5. 共有リンクを発行して家族に通知
6. コラボレーターが編集し、変更履歴を確認
7. 家系図を画像として出力して保存
